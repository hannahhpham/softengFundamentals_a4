# softengFundamentals_a4
Repository to store code for Software Engineering Fundamentals (Assignment 4). Group members are Hannah Pham, Annabell Jong, Angela Fenech, and Sanika Rahman.

# Setup Notes
- This project has been made with Maven as the build tool. Junit5 is used to run tests
- Please ensure you have JDK 21 and Maven installed
- Extensions to download: 'Github Actions' and 'Extension Pack for Java'

# Directory
- pom.xml: maven configuration (organises dependencies, plugins, java ver)
- App.java: main project code
- AppTest.java: for test classes
- Target/...:  generated by maven. DON'T TOUCH THIS PLEASEEE


# Running tests
- Navigate to the bus-driver-system folder and enter the command 'mvn test'
